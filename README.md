# 📥 Snapload

Aplicação web para download de vídeos do YouTube, Instagram e TikTok. Cole o link, baixe o vídeo — simples assim.

## ✨ Funcionalidades

- Download de vídeos do **YouTube**, **Instagram** e **TikTok**
- Interface web simples e intuitiva
- Suporte a diferentes qualidades de vídeo
- Processamento via backend Python

## 🛠️ Tecnologias

- Python
- Flask
- yt-dlp
- HTML / CSS / JavaScript

## 🚀 Como usar

1. Clone o repositório
```bash
git clone https://github.com/sup3rbi3l/snapload
cd snapload
```

2. Instale as dependências
```bash
pip install -r requirements.txt
```

3. Execute a aplicação
```bash
python app.py
```

4. Acesse no navegador
```
http://localhost:5000
```

5. Cole o link do vídeo e clique em baixar

## 📋 Requisitos

- Python 3.8+
- ffmpeg instalado no sistema
